One line, at most 120 characters, that gives the judge the funniest error message a kitchen toaster would show its owner: the toaster toasted the bread, the owner walked away and never came back, and the toaster has been sitting there warm ever since. Deadpan, quietly dramatic, no toaster pun anywhere — the joke is a small appliance that remembers being forgotten.

> ERROR: Your toast is ready. It has been ready since Tuesday. You forgot me again.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–120 characters, one line, not whitespace-only) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
